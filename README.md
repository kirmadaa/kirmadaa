**🎓 OnlineSkills: production AI platform on Kubernetes (k3s)** *(private repo)*
A multi-service monorepo (Next.js frontend, NestJS API, Python AI worker) taken to production on a k3s cluster. I built the delivery side: GitHub Actions CI (lint, typecheck, test, build), container images published to GHCR, day-2 deploys to the cluster, Cloudflare Tunnel for public access, and Docker Compose stacks for local, beta and monitoring.
